# Chaffinch starter

Reconcile sorted collection snapshots without materializing their union.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Chaffinch** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
1
2
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/chaffinch) · [View the release](https://github.com/Rahulchaube1/blyx-chaffinch/releases/tag/v0.1.0)
